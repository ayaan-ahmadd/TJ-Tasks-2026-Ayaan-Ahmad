# WboxGym
A simple and responsive gym website made using HTML, CSS and JavaScript.

## About the Project
WboxGym is a gym website where users can learn about the gym, check different membership plans, read member reviews, and contact the gym.

I made this project to practice frontend web development and get a better understanding of how HTML, CSS, and JavaScript work together to build a responsive website.

I created this website after learning the basics of HTML, CSS, and JavaScript over the last few months.

I tried to apply as much of what I’ve learned as possible and improve the website based on my current knowledge. This project helped me practice responsive design, styling, layouts, and basic JavaScript functionality while building something on my own.

## Approach
I started by planning the basic structure of the website and deciding what sections would be useful for a gym website.
**HTML** was used to create the structure and different sections of the website.
**CSS** was used for the layout, colors, typography, spacing, animations, and responsive design.
**JavaScript** was used to add basic interactions and functionality to the website.
I also made the website responsive so that it can work properly on different screen sizes.
I built the website step by step and tested the layout and functionality while making changes. I tried to use the concepts I had learned and improve the design as much as possible based on my current knowledge.

## Responsive Design

The website is designed to work properly on different screen sizes, including:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adjust the layout for smaller screens.

## JavaScript

JavaScript is used for the mobile navigation menu and contact form.

The mobile menu opens and closes when the menu button is clicked. The contact form also displays a message after it is submitted.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open 'index.html' in a web browser.

No installation or additional setup is required.
